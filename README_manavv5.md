## `$ whoami`

Hey! I'm **Manav Sharma**, an Electronics and Communication Engineering undergraduate at **IIIT Nagpur** (Class of 2029).

I'm interested in the space where **digital hardware meets software** — designing logic, describing it in Verilog, simulating it, and eventually seeing it work on an FPGA. I'm currently strengthening my digital design fundamentals while exploring RTL design, FPGA development, embedded systems, and SoC verification.

```text
> focus      : Digital Design | Verilog | FPGA
> board      : Sipeed Tang Nano 9K
> exploring  : RTL Design | SoC Verification | Embedded Systems
> mindset    : Learn it → Build it → Test it → Document it
```
